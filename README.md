# Финансовый напарник — обновления Android

**[Скачать последнюю версию APK](https://github.com/Jlapb-code/financial-companion-updates/releases/latest/download/financial-companion.apk)**

[Все выпуски и описание версии](https://github.com/Jlapb-code/financial-companion-updates/releases).
Нужен Android 8.0+. Файл называется `financial-companion.apk`.

Первый раз скачайте и установите APK. Затем приложение само проверяет новые
версии примерно раз в сутки при доступной сети. Можно проверить вручную:
**Настройки → Обновления по воздуху → Проверить обновления**.
Оно скачивает APK, проверяет размер, SHA-256, пакет и подпись и открывает
системный установщик. Android попросит подтвердить обновление.

**Не удаляйте старую версию перед обновлением**: установка поверх неё сохраняет
финансовую базу и ключ устройства. Сделайте свою копию .fnbk в настройках.
Если APK впервые открыт из браузера, разрешение установки нужно браузеру;
для обновления из приложения Android отдельно предложит разрешить установку
«Финансовому напарнику».

Приложение работает без регистрации, рекламы, AI и отправки финансовых данных.
База зашифрована на телефоне. По сети загружаются только общедоступные сведения
о версии и APK; GitHub при этом видит сетевой запрос. Суммы на экране округляются
вниз до целых рублей, но внутри расчётов сохраняются копейки.

Уведомления банков могут быть неполными и требуют сверки. Прогнозы показывают
последствия введённого плана, не гарантируют доходов и не являются выпиской банка.

`latest.json` в последнем Release — стабильный manifest обновления.
Файл в корне репозитория — читаемая копия для просмотра.
`signing-certificate.sha256` содержит публичный отпечаток сертификата.
Приватных ключей, паролей и финансовых данных в этом репозитории нет.
